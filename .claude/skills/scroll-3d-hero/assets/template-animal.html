A fox that moves as you scroll

Scroll down. It leaps when you scroll, runs when you hurry, and stands perfectly still when you stop.

Leap

The leap follows your scroll

The jump is tied to the scrollbar, not a timer. Stop halfway and the fox hangs in mid-air until you carry on.

Run

Scroll faster and it breaks into a run

Above a set speed the clip crossfades to a run. Stop scrolling and it eases back to standing.

Your animal here

Swap in any rigged model

Any glTF model with walk and idle clips works the same way. Point the runtime at your file and name its clips.

model: {
  url: 'snow-leopard.glb',
  animation: { idle: 'Idle', walk: 'Walk', run: 'Run' },
}
